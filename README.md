# Payas Days 日曆

Payas Days 是一款在瀏覽器中執行的個人日曆，支援月、週、日與議程檢視、重複事件、提醒，以及 ICS／Markdown 匯入與匯出。事件資料儲存在本機 IndexedDB，不需要帳號或後端服務。

## 開始使用

直接在瀏覽器中開啟 `index.html`，或在專案目錄啟動本機伺服器：

```bash
python3 -m http.server 8080
```

接著前往 `http://localhost:8080/`。首次使用會自動建立兩筆示範事件。
