# Payas Days

Payas Days 是一款以瀏覽器執行的個人日曆。無須帳號、建置流程或後端服務；事件與偏好設定會儲存在目前瀏覽器的 IndexedDB 中。

## 功能

- **五種檢視模式**：年曆總覽（月曆日期、不顯示事件）、月、週、日與未來 30 天議程，可快速切換或前往今天。
- **事件管理**：建立、編輯與刪除事件，支援全天事件、地點、Markdown 描述、顏色、標籤、參與者及附件網址；非全天事件至少 15 分鐘，且結束時間不可早於開始時間。
- **重複事件**：支援每日、每週、每月、每年，以及自訂 iCalendar RRULE。
- **提醒與衝突提示**：設定事件開始前的提醒時間，儲存時檢查行程是否重疊。
- **搜尋**：依事件標題、描述、地點或標籤搜尋。
- **資料匯入／匯出**：支援 ICS 與 Markdown 格式。
- **個人化介面**：支援淺色與深色主題，並適用於桌面和行動裝置。

## 開始使用

需要支援 IndexedDB 的現代瀏覽器，以及 Python 3（或其他靜態檔案伺服器）。建議在專案根目錄啟動本機伺服器：

```bash
python3 -m http.server 8080
```

接著在瀏覽器開啟 <http://localhost:8080/>。本專案不需要安裝相依套件或執行建置。Bootstrap、Font Awesome 與網頁字型由 CDN 載入，因此首次載入介面需要網路連線。

首次啟動時會自動建立兩筆示範事件。按右下角的「＋」可新增事件；在月檢視點擊日期格，也能建立預填該日期的事件。點擊事件可檢視詳情、編輯或刪除。

## 使用提示

- 使用標題列的左右箭頭切換日期範圍；按 `T` 回到今天。
- 按 `/` 開啟搜尋，按 `Escape` 關閉搜尋。
- 在「設定」頁面啟用瀏覽器通知，並在同一頁匯入或匯出資料。
- 匯出 ICS 可與其他行事曆工具交換事件；Markdown 檔案則適合備份或自行保存。

## 資料與提醒

事件資料儲存在目前瀏覽器的 IndexedDB 資料庫 `payas-days`，不會同步至雲端。清除瀏覽器網站資料可能會一併移除事件，建議定期匯出備份。

提醒需要授予瀏覽器通知權限，而且日曆頁面必須保持開啟；關閉頁面後，瀏覽器不會在背景繼續執行提醒計時器。

## 專案結構

```text
index.html                 應用程式入口與介面結構
css/styles.css             版面與主題樣式
js/app.js                  介面操作、事件表單、搜尋與初始化
js/calendar.js             日曆檢視與日期導覽
js/events.js               事件管理、衝突檢查與提醒
js/recurrence.js           重複事件展開
js/ics.js                  ICS 匯入與匯出
js/storage.js              IndexedDB 與 Markdown 資料處理
data/sample-event.md       Markdown 事件格式範例
```
